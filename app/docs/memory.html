Memory & Context Settings

Recent messages and a compact summary help your companion remember the conversation.

Conversation Memory

Memory Size

  • Range: 5 to 20 messages
  • Default: 20 messages
  • Controls the maximum recent messages sent, including your current message. Long messages can leave room for fewer older messages.

Summary Trigger

  • Range: 5 to 20 messages
  • Default: 20 messages
  • Starts a memory update when more messages are waiting, or older text becomes too large.

Summary Length Options

  • Ultra-Concise: 1 sentence summary
  • Concise: Short paragraph (default)
  • Detailed: 1-2 paragraphs
  • Comprehensive: More detail within the same memory limit

Manual Summarization

You can manually trigger summarization by clicking "Update Summary from Chat" in Memory Settings. The summary is stored in the "Conversation Summary" text area and can be manually edited.

Summaries aim for about 2 KiB and must fit within 4 KiB of UTF-8 text. The size indicator counts bytes, so emoji and some languages use more space per character. An oversized edit keeps your previously saved memory.

Memory updates process older text in parts. Pending messages stay saved until their update succeeds. A long message or older oversized summary may need several updates; progress survives a reload. Automatic updates run at most once per user turn and pause for two minutes after failure. You can use the manual button to continue.

After an oversized older summary is compressed, its original text remains in the saved chat backup and is included when you export chats.

WaifuAI Cloud requests fit within 32 KiB, with up to 16 KiB for older recent messages. Your newest message, personality instructions and accepted summary are preserved. If those alone cannot fit, shorten the message or instructions, or update memory before sending again.

Context Settings

The following information can be included in AI context:

Time Context

  • Includes current date and time in AI prompts
  • Enabled by default

Battery Status

  • Provides device battery level and charging state
  • Disabled by default (requires Battery API support)

Tutorial Context

  • Includes application tutorial in AI context
  • Allows AI to reference feature documentation

AI Settings Control

  • Allows AI to modify application settings
  • Experimental feature - use with caution

JSON Emotion Format

  • Forces AI to respond in JSON for emotional reactions
  • May cause errors on weaker LLM models
  • Disabled by default
